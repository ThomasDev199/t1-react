# 🚀 T1 React

Aplicación web desarrollada con **React y Vite**, como parte del proceso de aprendizaje y desarrollo frontend.

El proyecto utiliza herramientas modernas del ecosistema JavaScript para construir interfaces dinámicas, reutilizables y adaptables a diferentes dispositivos.

## 🛠️ Tecnologías utilizadas

| Tecnología | Descripción |
|---|---|
| React 19 | Biblioteca para construir interfaces de usuario |
| Vite 8 | Herramienta de desarrollo y compilación |
| JavaScript | Lenguaje principal del proyecto |
| Bootstrap 5 | Framework de estilos CSS |
| React Bootstrap | Componentes de Bootstrap para React |
| React Router DOM 7 | Gestión de rutas y navegación |
| Oxlint | Análisis estático y revisión del código |

## 📋 Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- [Node.js](https://nodejs.org/)
- npm (incluido con Node.js).
- [Git](https://git-scm.com/).
- Visual Studio Code (recomendado).

## ⚙️ Instalación

Sigue estos pasos para ejecutar el proyecto localmente.

**1. Clonar el repositorio**

```bash
git clone https://github.com/ThomasDev199/t1-react.git
```

**2. Entrar a la carpeta**

```bash
cd t1-react
```

**3. Instalar las dependencias**

```bash
npm install
```

**4. Iniciar el servidor de desarrollo**

```bash
npm run dev
```

Vite mostrará una dirección local en la terminal. Generalmente:

```text
http://localhost:5173/
```

Abre esa dirección en tu navegador.

## 📜 Scripts disponibles

| Comando | Función |
|---|---|
| `npm run dev` | Inicia el servidor de desarrollo |
| `npm run build` | Genera la versión de producción |
| `npm run preview` | Previsualiza la compilación |
| `npm run lint` | Analiza el código con Oxlint |

## 🏗️ Compilación para producción

Para generar los archivos optimizados:

```bash
npm run build
```

Los archivos generados se guardarán en la carpeta `dist/`.

Para visualizar la compilación:

```bash
npm run preview
```
